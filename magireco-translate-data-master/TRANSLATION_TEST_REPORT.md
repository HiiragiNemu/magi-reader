## 六、功能性文本保护

仅以下 19 个字段被视为玩家可见文本并参与翻译，其余全部字段与数值均按源文件原样保留：

```
Fnarration
nameAvCenter
nameAvLeft
nameAvRight
nameCenter
nameFnarration
nameLeft
nameNarration
nameRight
narration
progressFnarration
progressNarration
textAvCenter
textAvLeft
textAvRight
textCenter
textLeft
textRight
textSelect
```

自动校验规则（每次构建后全量执行）：

- JSON 结构与源文件完全一致（键路径集合相同）
- 所有非文本字段值逐字节相同
- `@` 强制换行符数量不变
- 引擎指令标记（`[se:]` `[wait:]` `[chara:]` `[flashEffect:]` 等）逐字保留
- 颜色标记（`[textRed:]` 等）数量与顺序不变，仅翻译其内部文字
- 译文中不残留日文假名
